# healthcare-readmission-powerbi-dashboard

This project uses hospital encounter data to build a Power BI dashboard focused on patient readmission patterns and healthcare operational metrics. The goal is to practice healthcare data analysis and visualize factors associated with higher hospital readmission rates.

## Project Goals

- Analyze hospital readmission outcomes
- Calculate overall and 30-day readmission rates
- Explore how age, hospital stay length, and medication burden relate to readmission
- Build an interactive healthcare dashboard using Power BI
- Practice healthcare-focused business intelligence and data visualization

## Dataset

This project uses the Diabetes 130-US Hospitals dataset, which contains patient encounter records from U.S. hospitals between 1999 and 2008.

The dataset includes variables such as:

- Age group
- Gender
- Race
- Time in hospital
- Number of medications
- Number of lab procedures
- Readmission outcome

## Dashboard Features

- KPI cards for total encounters, readmission rate, 30-day readmission rate, and average hospital stay length
- Readmission rate by age group
- Readmission rate by hospital stay length
- Readmission rate by medication burden
- Interactive slicers for demographic filtering

## Tools Used

- Power BI
- DAX
- Power Query

## Key Observations

The dashboard suggests that readmission risk varies across patient age groups, medication burden, and hospital stay length. Longer hospital stays and higher medication counts appear to be associated with higher readmission rates.
