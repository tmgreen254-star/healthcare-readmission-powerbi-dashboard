# Healthcare Readmission Power BI Dashboard
This project uses hospital encounter data to build a Power BI dashboard focused on patient readmission patterns and operational risk factors. The goal is to practice healthcare analytics by identifying patient groups and hospital stay patterns associated with higher readmission rates.
## Project Goals
- Analyze hospital readmission outcomes
- Calculate overall and 30-day readmission rates
- Compare readmission rates across age groups and hospital stay lengths
- Explore medication burden and lab procedure patterns
- Build an interactive dashboard for healthcare operations insights
## Dataset
This project uses the Diabetes 130-US Hospitals dataset, a publicly available dataset containing patient encounter records from U.S. hospitals between 1999 and 2008.
The dataset includes:
- Patient demographics
- Admission and discharge information
- Time in hospital
- Number of medications
- Number of lab procedures
- Diagnosis information
- Readmission outcome
## Tools Used
- Power BI
- DAX
- Power Query
- Excel/CSV data preparation
## Dashboard Pages
### Executive Overview
Summarizes total encounters, readmission rate, 30-day readmission rate, average hospital stay, and medication burden.
### Patient Risk Factors
Compares readmission rates across age groups, medication groups, and hospital stay lengths.
### Clinical and Operational Insights
Highlights patterns that may help hospitals identify patient groups with higher readmission risk.
## Key Insights
The dashboard suggests that readmission risk varies by patient age, length of hospital stay, and medication burden. These patterns can help support hospital quality improvement efforts, care coordination, and follow-up planning.
